# 数据清理与智能体批量导入

状态：已实现并完成本轮 Web 验证。2026-10-12。

## 管理行为

- 数据集为累积的不可变快照。删除所选或全部快照，同时删除关联结果；删除历史快照不重建后代。只删插件内副本，不删源文件。
- 最近导入撤销删除最新成功导入快照，恢复其父快照，父不存在时用最近保留快照；演示排除。当前数据被删除时回退，无剩余时为空。
- UI 先预览，再弹窗确认；对象、结果或当前选择变化使确认失效。运行导入／算法的项目不能删除。数据删除不开放给智能体。
- 删除使用 prepared journal 与状态提交标记，提交前崩溃恢复目录，提交后崩溃清理暂存删除目录。保留交接文字和会话，移除失效输入／结果引用、提案和地图缓存。
- 终态任务仅隐藏／恢复展示，状态持久化。运行中任务不能清理；数据、结果与源文件不受影响。

## 批量导入

- 四个专用工具：linggo_projects、linggo_prepare_import、linggo_commit_import、linggo_import_status。原生用户消息 source.kind=user 才能授权来源，插件介绍／relay／工具／文件内容不能授权。
- 只读取用户指定路径或明确要求的当前目录；默认递归，深度最多16、目录项10000、每批200个文件／1GiB。跳过隐藏、依赖、输出目录与符号链接，不自动访问 PostGIS。
- 复用 CSV、Excel 多工作表、GeoJSON、Shapefile、GTFS 管线。字段映射仅声明式转换；未知坐标系、方向、字段候选、主键冲突和无主键重叠集中提问，坏行不静默发布。
- 同实体非冲突编号合并、同主键完全相同记录去重；实体默认替换、未涉及实体继承。append 需用户明确要求。整批检查关联后一次发布一个快照。
- 计划归属发起会话，有效30分钟，绑定源文件 SHA256、项目和基准快照；变更需重新准备。同计划重复提交使用同一个任务。同项目导入／运行／删除跨 Host 互斥。
- 失败或取消清理暂存目录，不发布部分数据。无项目时在插件根目录建立目录名项目及双工作区；成功后关联会话并更新地图，不发送消息或修改草稿。
- 缺 Python 返回环境初始化指引，不自动下载。人工向导、PostGIS、算法确认运行和展示 shell 守卫保留。

## 状态与 API

schema 5 增加 importPlans、sessionProjects、operations、deletedTransactions；任务 hidden 为可选字段。旧状态迁移默认空集合，不改旧记录。

UI API：previewDeleteData／deleteData、setJobsHidden，以及 jobs 的 includeHidden。删除确认 token 绑定预览对象；只有 done／failed／cancelled 可隐藏或恢复。
