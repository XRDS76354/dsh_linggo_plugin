# LingGo 数据导入

数据只能由用户在工作台左侧“数据”页的导入向导中导入；你不能替用户导入或改写数据。

步骤（告诉用户在界面上怎么做）：
1. 选择来源：本机文件（CSV / Excel / Shapefile / GeoJSON / GTFS zip）或 PostGIS 连接串。
2. 选择目标数据类型：站点、线路与方向、线路站序、时刻表、分时段客流、OD、逐笔需求、车辆、车场等。
3. 字段映射：系统根据列名给出建议，用户逐项确认；坐标系（WGS84 / GCJ-02 / BD-09）必须由用户选择。
4. 预览：查看前若干行转换结果、错误行和警告（例如只有一个方向的线路、远离主要范围的站点）。
5. 确认导入：后台任务生成新的不可变数据版本，可取消；旧版本保留，可切换。

回答原则：
- 先调用 linggo_status 查看已有数据和缺失项，再建议下一步导入什么。
- 线路方向不会自动推断：站序编码不统一时，请用户在源数据里明确方向字段。
- 不要编造数据，也不要假定项目有 GPS、客流或逐笔需求。
